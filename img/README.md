# Carpeta de Imágenes para Himnario PIB

Esta carpeta (`img/`) está preparada para alojar el logo y los iconos del sitio web.

## Archivos requeridos

### 1. Logo del Header (`logo.png`)
- **Ubicación:** `img/logo.png`
- **Uso:** Se muestra en el encabezado dentro del `<div class="logo-circle">`.
- **Recomendación:** Imagen cuadrada (ej. `512x512` px), preferiblemente en formato PNG con fondo transparente o forma circular.

### 2. Iconos de la Web / Favicon (`icon.png`)
- **Ubicación principal:** `img/icon.png`
- **Uso:** Icono de la pestaña del navegador (favicon) y acceso directo.
- **Variantes de tamaño recomendadas (opcionales para mayor compatibilidad en móviles y dispositivos):**
  - `img/icon-16x16.png` (Favicon pequeño 16x16 px)
  - `img/icon-32x32.png` (Favicon estándar 32x32 px)
  - `img/apple-touch-icon.png` (Icono para iOS/Apple 180x180 px)

---
*Nota: Solo necesitas reemplazar o colocar tus archivos con los nombres indicados en esta carpeta y la página los cargará automáticamente.*
